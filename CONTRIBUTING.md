## CONTRIBUTING

Thank you for your interest in contributing to this project! Please follow the guidelines below to get started:

### Setting up the Project Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repository.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repository
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Running Tests
To ensure your changes do not break existing functionality:
```bash
pytest
```

### Submitting a Pull Request
1. Create a feature branch:
   ```bash
   git checkout -b your-feature-branch
   ```
2. Make your changes and commit them with clear commit messages.
3. Push your changes:
   ```bash
   git push origin your-feature-branch
   ```
4. Open a pull request on GitHub.

Thank you for your contributions!
